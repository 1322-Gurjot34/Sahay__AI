## 💡 What is SAHAY AI?

SAHAY AI acts as an accessibility intelligence layer between a person and their environment.

Instead of simply identifying objects, SAHAY focuses on:

**Person + Environment + Constraints → Safest & Most Accessible Action**

The same environment can require completely different recommendations depending on the user's accessibility needs.

For example:

- A person with mobility needs may be guided toward a ramp instead of stairs.
- A visually impaired user can receive environmental descriptions and guidance.
- A hearing-impaired user can receive visual alerts.
- A user who needs cognitive assistance can receive simplified step-by-step instructions.

SAHAY currently supports different user needs:

| Profile | Purpose |
|---|---|
| Vision | Environmental understanding and visual assistance |
| Mobility | Accessible paths, ramps, elevators and obstacles |
| Hearing | Visual awareness and alerts |
